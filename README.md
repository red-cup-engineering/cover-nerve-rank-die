This package carries one placement-independent behavior:

`h0rank = components`

`h1rank = cells + components - entities`

under the admitted finite CoverNerve bounds. It emits the coordination-free
flag and the equal Landauer/coordination readouts. Its public byte pinout is
canonical typed RMN with RFC 8949 deterministic-CBOR bytes and RFC 6920 `ni`
identity.

The behavior is an executable projection of separately proved Obsmetrologia
declarations. It is not a formally verified extraction. The Mathematical
Readout Exchange is one enterprise that offers this package over a signed
network face.
